This project will be focusing on how Object Detection AI can be implemented with Unmanned Aerial Vehicles (UAVs), to detect and identify potholes from images, as well as real-time footage. Using Single Board Computers (SBC) such as Raspberry Pi's, the YOLO based object detection model can be trained and implemented, so the SBC can detect and identify potholes through the use of an external camera.

The SBC can then be integrated onto a lightweight UAV, where the real-time in-flight pothole detection video will be streamed to a machine on the ground, for the UAV operator to see. The reasoning behind implementing an object detection model into a UAV, is so that the UAV can fly over roads and other urban areas, in real-time and identify potholes with greater effectiveness in comparison to what a ground vehicle might possess, due to the UAV's aerial capabilities. The aerial capabilities will allow for the camera to pick up a wider area from an aerial view.
